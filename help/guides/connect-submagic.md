Submagic adds captions or polishes each clip, instead of the built-in editor, using your Submagic credits. Everything works
without it.

## Open Submagic

![Step 1](/help/screenshots/connect-submagic-1.png)
<!-- route: external -->

Go to [submagic.co](https://submagic.co) and log in. Open **Settings**, then **API** (the Business + API plan).

## Create a key and copy it

![Step 2](/help/screenshots/connect-submagic-2.png)
<!-- route: external -->

Create a key, name it **Sheila Studio**, and copy it.

## Paste it and tap Check key

![Step 3](/help/screenshots/connect-submagic-3.png)
<!-- route: /settings/connections -->
<!-- target: role=textbox[name="Editor · Submagic key"] -->

In the dashboard open **Settings**, then **Connections**, **Editing apps**. Paste the key in the
**Submagic** card and tap **Check key**.

## Pick it under Who edits

![Step 4](/help/screenshots/connect-submagic-4.png)
<!-- route: /settings -->
<!-- target: section[aria-label="Editing"] -->

Open **Settings**, then **Editing**, **Who edits**, and pick **Submagic**.

## Did this work?

The card says **Connected**. If it says the key is not valid, copy the whole key again. If your
plan has no API access, Submagic says so; the built-in editor keeps working.
